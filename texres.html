TeXres

A TeX distribution in a single executable, written in Rust. It compiles LaTeX documents with pdfLaTeX, XeLaTeX or LuaLaTeX, and includes the LaTeX formats, a package archive, fonts, BibTeX and Biber. You don't need TeX Live, and nothing is downloaded during a build.

command: texres macOS, Windows, Linux x86_64 and ARM64 Homebrew tap AUR: texres-bin MIT / Apache-2.0
texres paper.tex runs LaTeX, BibTeX or Biber as many times as needed and writes paper.pdf. The project was previously called ratex; the old GitHub URLs redirect to github.com/leoliu0/texres.

Features

Three engines

pdfLaTeX, XeLaTeX and LuaLaTeX. Documents loading fontspec, xeCJK, ctex, unicode-math or polyglossia run as XeLaTeX automatically; everything else runs as pdfLaTeX. Override with -pdf, -xelatex or -lualatex.

BibTeX and Biber built in

\bibliography runs BibTeX. biblatex with the default backend=biber runs the built-in Biber, which writes the same .bbl as Biber 2.22. Works offline.

Self-contained

LaTeX formats, a package archive and fonts are bundled. No TeX Live needed, and nothing is downloaded during a build. Output is compared against TeX Live 2026 in CI.

Fonts

Bundled fonts include Latin Modern, TeX Gyre, STIX Two, Libertinus, IPAex, Harano Aji and Fandol. System fonts are not used; to use another font, put the file next to your document and load it with Path=./.

One command

texres paper.tex runs LaTeX, BibTeX or Biber as many times as needed. A symlink named pdflatex, xelatex, lualatex, bibtex or biber runs one pass of that tool; named latexmk it behaves like texres. An existing TeX Live is left alone.

SyncTeX, latexdiff, libraries

Writes .synctex.gz for editor jump-to-source. Includes texres latexdiff. A C library and a WebAssembly module compile documents in memory (docs).

Usage and editor setup

Command line

# engine picked from the preamble
texres paper.tex
# or -pdf, -lualatex
texres -xelatex paper.tex
# write output to build/
texres -output-directory=build paper.tex
# remove cached build files
texres -c paper.tex
# compare two versions
texres latexdiff old.tex new.tex diff.tex && texres diff.tex

texres --help lists all options. Exit status: 0 converged, 1 build failed, 2 usage error.

Editors need the full path to texres. Find it with command -v texres (Homebrew: "$(brew --prefix)/bin/texres").

TeXstudio

1. Options → Configure TeXstudio → Commands: set Latexmk to (using your path)
   "/opt/homebrew/bin/texres" -pdf -interaction=nonstopmode "%.tex"
2. Under Build, choose Latexmk as the default compiler.
# Use the full path: macOS apps started from the Dock don't see your shell PATH.

VS Code (LaTeX Workshop)

// add to settings.json
"latex-workshop.latex.tools": [
  {{ "name": "texres", "command": "texres", "args": ["-pdf", "-interaction=nonstopmode", "%DOC%"] }}
],
"latex-workshop.latex.recipes": [{{ "name": "texres", "tools": ["texres"] }}]

The .synctex.gz file next to the PDF lets the editor jump between source and PDF. More: README, error messages, performance. Bug reports and papers that don't compile are welcome at github.com/leoliu0/texres/issues.
