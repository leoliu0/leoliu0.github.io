Delta (\(\Delta\)) 敏感度

  • 定义： Delta 是期权价格 \(f\) 相对于标的资产价格 \(S\) 的变化率（一阶偏导数）：
    \[ \Delta = \frac{\partial f}{\partial S} \]
  • 无红利资产的欧式看涨与看跌期权：
    \[ \Delta_{\text{call}} = N(d_1) > 0, \quad \Delta_{\text{put}} = N(d_1) - 1 < 0 \]
  • Delta 取值范围：
    • 看涨期权 Delta 介于 \(0\) 至 \(+1\) 之间（平值 \(\text{ATM} \approx 0.5\)，深度实值 ITM \(\to 1\)，深度虚值 OTM \(\to 0\)）。
    • 看跌期权 Delta 介于 \(-1\) 至 \(0\) 之间（平值 \(\text{ATM} \approx -0.5\)，深度实值 ITM \(\to -1\)，深度虚值 OTM \(\to 0\)）。

Delta 的核心性质

  • 斜率的几何含义： Delta 是期权价格关于标的资产价格 \(S\) 曲线上的切线斜率：
    \[ \text{切线斜率} = \Delta = \lim_{\Delta S \to 0} \frac{\Delta f}{\Delta S} \]
  • Delta 与到期时间的关系：
    • 当到期时间 \(T \to 0\) 时，Delta 曲线在执行价格 \(K\) 附近显著变陡：
      • 对于实值看涨期权（\(S > K\)）：\(\Delta \to 1.0\)
      • 对于虚值看涨期权（\(S < K\)）：\(\Delta \to 0.0\)
      • 对于平值看涨期权（\(S = K\)）：\(\Delta \approx 0.5\)，呈现阶跃函数的形态过渡。

Delta 的性质（一阶线性近似）

  • Delta 衡量期权价值对标的资产价格微小变动的敏感度：
    • 若标的价格 \(S\) 变动 \(\Delta S\)，则：
      • 看涨期权价值变动约为 \(\Delta_c \times \Delta S\)
      • 看跌期权价值变动约为 \(\Delta_p \times \Delta S = -|\Delta_p| \times \Delta S\)
  • 数值算例：
    股票价格从 $49.00 上涨至 $50.50（\(\Delta S = +\$1.50\)）。
    该股票看涨期权的 Delta 为 0.43。
    预计该看涨期权价值将上涨： \[ \Delta \times \Delta S = 0.43 \times \$1.50 = \mathbf{\$0.645} \]
  • 对于深度实值期权：\(\Delta_{\text{call}} \approx 1, \quad \Delta_{\text{put}} \approx -1\)。
  • 对于深度虚值期权：\(\Delta_{\text{call}} \approx 0, \quad \Delta_{\text{put}} \approx 0\)。

远期与期货合约的 Delta

  • 标的现货资产本身的 Delta 恒为 \(\mathbf{1}\)。
  • 支付连续红利率 \(q\)、期限为 \(T\) 的资产远期合约的 Delta：
    \[ \Delta_{\text{forward}} = e^{-qT} \quad (\text{若 } q = 0 \implies \Delta_{\text{forward}} = 1) \]
  • 支付连续红利率 \(q\)、期限为 \(T\) 的资产期货合约的 Delta：
    \[ \Delta_{\text{futures}} = e^{(r - q)T} \]
  • 典型期货实例：
    • 股指期货：\(\Delta = e^{(r - q)T}\)
    • 外汇期货：\(\Delta = e^{(r - r_f)T}\)（\(r_f\) 为外国无风险利率）
    • 商品期货（黄金/白银）：\(\Delta = e^{rT}\)

期权合约的 Delta

  • 以支付连续红利率 \(q\)、期限为 \(T\) 的资产为标的的期权合约 Delta：
    \[ \Delta_{\text{call}} = e^{-qT} N(d_1), \quad \Delta_{\text{put}} = e^{-qT} [N(d_1) - 1] \]
  • 各类衍生品期权具体形式：
    • 股指期权： \(\Delta_c = e^{-qT} N(d_1), \quad \Delta_p = e^{-qT} [N(d_1) - 1]\)
    • 外汇期权： \(\Delta_c = e^{-r_f T} N(d_1), \quad \Delta_p = e^{-r_f T} [N(d_1) - 1]\)
    • 期货期权： \(\Delta_c = e^{-rT} N(d_1), \quad \Delta_p = e^{-rT} [N(d_1) - 1]\)
  • 其中代入相应参数计算 \(d_1\)： \[ d_1 = \frac{\ln(S_0 / K) + (r - q + \frac{1}{2}\sigma^2)T}{\sigma \sqrt{T}} \]

Theta (\(\Theta\)) 时间衰减

  • 定义： Theta 是期权价格 \(f\) 相对于时间流逝 \(t\) 的变化率（时间价值损耗速率）：
    \[ \Theta = \frac{\partial f}{\partial t} \]
  • 支付连续红利率 \(q\) 资产的欧式看涨期权 Theta：
    \[ \Theta_c = -\frac{S_0 N'(d_1) \sigma e^{-qT}}{2\sqrt{T}} - r K e^{-rT} N(d_2) + q S_0 N(d_1) e^{-qT} \]
    其中 \(N'(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2 / 2}\)。
  • 期权多头的 Theta 通常为负值 – 随着时间流逝，期权不断损失时间价值。
  • 算例： \(S_0 = 49, K = 50, r = 0.05, \sigma = 0.20, T = 20/52\)： \[ \Theta = -4.31 \text{ / 年} = \frac{-4.31}{252} = \mathbf{-0.0171} \text{ / 交易日} \] 这意味着该期权价值每个交易日因时间流逝自然衰减约 $0.0171。

Theta 的性质与特征

  • Theta 与标的资产价格的关系：
    • 参数设定：\(K = 50, r = 0.08, \sigma = 0.25, T = 0.5\)。
    • 当期权处于平值状态（\(\text{ATM}, S \approx K = 50\)）时，Theta 负值绝对值最大（时间价值损耗速度最快）。
    • 对于深度实值或深度虚值期权，Theta 趋近于 0（因为期权价格被内在价值主导，或者外在时间价值本身极小）。
  • Theta 与到期时间的关系：
    • 对于平值期权，随着到期日临近（\(T \to 0\)），时间衰减急剧加速。
    • 交易员持有临近到期的平值多头期权时，必须警惕严峻的日度时间价值侵蚀。

Gamma (\(\Gamma\)) 曲率

  • 定义： Gamma 是 Delta (\(\Delta\)) 相对于标的资产价格 \(S\) 的变化率（期权价格对标的资产价格的二阶偏导数）：
    \[ \Gamma = \frac{\partial \Delta}{\partial S} = \frac{\partial^2 f}{\partial S^2} \]
  • 欧式看涨与看跌期权公式（两者完全相同！）：
    \[ \Gamma = \frac{N'(d_1)}{S_0 \sigma \sqrt{T}} \quad \text{若含连续红利率 } q: \quad \Gamma = \frac{N'(d_1) e^{-qT}}{S_0 \sigma \sqrt{T}} \]
  • 若标的价格变动 \(\Delta S\)，Delta 的变动量约为 \(\Gamma \times \Delta S\)。
  • 算例： \(S_0 = 49, K = 50, r = 0.05, \sigma = 0.20, T = 20/52 \implies \Gamma = 0.066, \Delta = 0.5216\)。
    若股票价格从 $49 上涨至 $50.50（\(\Delta S = \$1.50\)）： \[ \Delta_{\text{new}} \approx 0.5216 + (0.066 \times 1.50) = 0.5216 + 0.099 = \mathbf{0.6206} \]

Gamma 的性质

  • 虚实值程度对 Gamma 的影响：
    • 深度虚值（Deep OTM）： Delta \(\approx 0\)，随 \(S\) 变动极慢 → \(\Gamma \approx 0\)。
    • 平值状态（ATM）： Delta \(\approx 0.5\)，对标的价格微小变动极度敏感 → \(\mathbf{\Gamma}\) 达到峰值最大值！
    • 深度实值（Deep ITM）： Delta \(\approx 1.0\)，随 \(S\) 变动极慢 → \(\Gamma \approx 0\)。
  • Gamma 与标的资产价格的关系：

    Gamma 随标的资产价格呈现以执行价格 \(S = K\) 为对称中心的尖锐钟形峰值曲线。

  • 对冲者必须高度关注持有平值期权的组合，其 Gamma 风险极为集中。

Gamma 的性质与曲率修正

  • Gamma 与到期时间的关系：
    • 当 \(T \to 0\) 时，平值期权的 Gamma 趋于无穷大，导致在 \(S = K\) 附近的敏感度极端集中。
  • Gamma 刻画了 Delta 对冲中的二阶曲率效应：
    • 若 \(\Gamma\) 较小：Delta 变动缓慢 → 较低频率的再平衡即可满足要求。
    • 若 \(\Gamma\) 较大：Delta 高度敏感 → 若不及时调整对冲比例，将引发严重的跟踪误差！
  • 曲率增益直观示例：
    在 \(S = 49\) 时，看涨期权价格为 $2.40（\(\Delta = 0.52\)）。若股票上涨至 $50（\(\Delta S = +1\)）：
    一阶线性 Delta 预测值：\(2.40 + 0.52 \times 1 = \mathbf{\$2.92}\)
    考虑非线性曲率后的实际看涨期权价格：\(\mathbf{\$2.95}\)
    多出的 +$0.03 正是二阶曲率带来的正向收益（\(\frac{1}{2}\Gamma \Delta S^2\)）！

Delta、Theta 与 Gamma 之间的内在关系

头寸方向Delta (\(\Delta\))Gamma (\(\Gamma\))Theta (\(\Theta\))
多头看涨 (Long Call)++−
多头看跌 (Long Put)−+−
空头看涨 (Short Call)−−+
空头看跌 (Short Put)+−+

对于 Delta 中性组合（\(\Delta_P = 0\)），由泰勒级数展开可得：

\[ \Delta \Pi \approx \Theta \Delta t + \frac{1}{2} \Gamma (\Delta S)^2 \]
  • 当 \(\Gamma > 0\)（此时 \(\Theta < 0\)）：若标的价格不移动（\(\Delta S = 0\)），组合遭受 \(\Theta\) 时间衰减损失；但若标的价格大幅跳变，组合将通过 \(\Gamma\) 获取丰厚曲率收益！
  • 当 \(\Gamma < 0\)（此时 \(\Theta > 0\)）：若标的价格平稳不移动，组合赚取正向时间价值损耗收益；但一旦标的价格大幅跳变，组合将遭受严重损失！

Vega (\(\mathcal{V}\)) 波动率敏感度

  • 定义： Vega 是期权价格 \(f\) 相对于标的资产波动率 \(\sigma\) 的变化率：
    \[ \mathcal{V} = \frac{\partial f}{\partial \sigma} \]
  • 欧式看涨与看跌期权公式（两者完全相同）：
    \[ \mathcal{V} = S_0 \sqrt{T} N'(d_1) \quad \text{若含连续红利率 } q: \quad \mathcal{V} = S_0 \sqrt{T} N'(d_1) e^{-qT} \]
  • 无论看涨期权多头还是看跌期权多头，Vega 恒为正值。
  • 经济含义： 若标的波动率 \(\sigma\) 上升 1%（0.01），期权价格相应上涨约 \(0.01 \times \mathcal{V}\)。
  • 平值期权（ATM）的 Vega 达到最高，随着深入实值或虚值逐渐下降。

Rho (\(\rho\)) 利率敏感度

  • 定义： Rho 是期权价格 \(f\) 相对于无风险利率 \(r\) 的变化率：
    \[ \rho = \frac{\partial f}{\partial r} \]
  • 欧式期权计算公式：
    \[ \rho_{\text{call}} = K T e^{-rT} N(d_2) > 0, \quad \rho_{\text{put}} = -K T e^{-rT} N(-d_2) < 0 \]
  • 经济含义： 若利率 \(r\) 上升 1%（0.01），期权价格相应变动约 \(0.01 \times \rho\)。
  • 外汇期权中的双 Rho 参数：
    • 本国利率 Rho（\(\rho_{\text{domestic}}\)），衡量对本国无风险利率 \(r\) 的敏感度。
    • 外国利率 Rho（\(\rho_{\text{foreign}}\)），衡量对外国无风险利率 \(r_f\) 的敏感度。

希腊字母组合管理：Delta、Gamma 与 Vega 的协同控制

  • 期权投资组合的整体希腊字母是其各个成分合约希腊字母的加权和：
    \[ \Delta_P = \sum_{i=1}^n w_i \Delta_i, \quad \Gamma_P = \sum_{i=1}^n w_i \Gamma_i, \quad \mathcal{V}_P = \sum_{i=1}^n w_i \mathcal{V}_i \]
  • 实现 Delta 中性（\(\Delta_P = 0\)）： 可通过持有标的现货资产或期货合约达成（现货与期货的 \(\Gamma = 0, \mathcal{V} = 0\)）。
    • 若期货头寸为 \(w_F\)，现货头寸为 \(w_S\)：\(w_F = e^{-(r-q)T^*} w_S\)。
  • 实现 Gamma 与 Vega 中性（\(\Gamma_P = 0, \mathcal{V}_P = 0\)）：
    • 标的现货与期货合约的 \(\Gamma\) 与 \(\mathcal{V}\) 恒为零。
    • 因此，要调节组合的 Gamma 或 Vega，必须在组合中额外加入场内挂牌的期权合约！

案例 – Delta 与 Gamma 综合对冲

某金融机构持有美元场外期权组合，敏感度为 \(\Delta = -450\)，\(\Gamma = -6,000\)。市场上有一只可交易期权，其参数为 \(\Delta_T = 0.6, \Gamma_T = 1.5\)。

  • 需要持有多少单位可交易期权（\(w\)）和美元现货（\(w_S\)）才能使该组合同时达到 Gamma 中性与 Delta 中性？
  • Gamma 与 Delta 中性联立条件：
    \[ \Gamma: \quad -6,000 + w \times 1.5 + w_S \times 0 = 0 \] \[ \Delta: \quad -450 + w \times 0.6 + w_S \times 1 = 0 \]
  • 求解方程组： \[ w = \frac{6,000}{1.5} = \mathbf{4,000 \text{ 份可交易期权}} \] \[ w_S = -(-450 + 4,000 \times 0.6) = -( -450 + 2,400) = \mathbf{-\$1,950} \]
  • 对冲策略： 买入 4,000 份可交易期权，并在现货市场做空 $1,950 的标的货币。

案例 – Delta、Gamma 与 Vega 联合对冲

某场外期权组合的敏感度为 \(\Delta = -450, \Gamma = -6,000, \mathcal{V} = -4,000\)。市场上有两只可交易期权：

风险对冲的权衡考量：曲率、波动率与再平衡频率

Delta 中性 (\(\Delta = 0\))
一阶线性保护。 切线拟合。防范微小的价格渐进变动。利用高流动性现货股票或期货易于执行。
Gamma 中性 (\(\Gamma = 0\))
二阶曲率保护。 二次抛物线拟合。防范再平衡间隔期间的价格大幅跳变。消除 \(\Delta\) 的快速漂移。
Vega 中性 (\(\mathcal{V} = 0\))
波动率冲击保护。 防范市场突发体制转变与隐含波动率激增（例如金融危机或黑天鹅事件）。

实务中连续对冲与离散对冲的权衡：

  • BSM 理想状态： 零摩擦的连续再平衡可实现完全无风险对冲（\(\Delta \Pi = 0\)）。
  • 市场现实： 真实交易中，高频连续再平衡会产生巨大的交易手续费与买卖价差摩擦损耗。
  • 离散跟踪误差： 在离散时间间隔 \(\Delta t\) 内，未对冲的跟踪误差满足：\(\Delta \Pi \approx \frac{1}{2} \Gamma (\Delta S)^2 + \Theta \Delta t + \mathcal{V} \Delta \sigma\)。
  • 机构折中策略： 每日利用低成本现货或期货维持 Delta 中性，当挂牌期权具有经济可行性时，阶段性调整对冲 Gamma 与 Vega。

止损对冲策略 (Stop-Loss Strategy)

  • 策略机制：
    • 一旦股票价格突破执行价格 \(K = \$50\)，立刻买入 100,000 股股票。
    • 一旦股票价格跌破执行价格 \(K = \$50\)，立刻卖出 100,000 股股票。
  • 理论直觉： 期权在实值时持有股票（形成备兑），期权在虚值时持有现金（避免股票跌价）。
  • 为何在实务中必然失败：
    • 反复拉锯震荡亏损（Whipsaw Losses）： 当股票价格在 $50 附近反复震荡时，交易员不断高买（$50.05）低卖（$49.95），资金迅速失血！
    • 价格跳空与滑点（Gapping & Slippage）： 市场价格跳跃离散，买入和卖出根本无法精确在 $50.00 成交。
    • 货币时间价值： 现金流发生在不同时间点，必须进行折现考量。

  • BSM 模型的理论基石： 由 \(\Delta\) 单位标的资产和 1 单位衍生品空头构成的资产组合在局部瞬时是完全无风险的：

    • 必须定期或连续再平衡持仓，才能维系 Delta 中性状态。

动态对冲与静态对冲的对比分析

  • 动态对冲期权的总成本现值约等于其 Black-Scholes 理论价值（$240,000）。
  • 动态对冲组合构建了期权的合成多头头寸，从而精确中和了期权卖方的空头敞口。
  • 再平衡频率的权衡： 提高再平衡频率可以降低跟踪误差及对冲成本的波动，但会显著增加累积的交易手续费。
  • 利用远期合约进行静态对冲：
    • 由于远期合约的 Delta 恒等于 1（\(\Delta = 1\)），由 1 股标的股票多头与 1 份远期合约空头构成的组合完全不需要任何再平衡！
    • 远期合约可以实现“对冲后即可高枕无忧”（静态对冲）。而期权因具有内在非线性曲率，本质上依赖动态 Delta 对冲。
