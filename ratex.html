ratex

An ultra-fast, self-contained, pure-Rust TeX engine and build toolchain designed as a modern, high-performance replacement for pdflatex and latexmk.

Key Architecture

Design Highlights

⚡ Sub-10ms Incremental Builds

Built-in cryptographic auxiliary state tracking and dependency graph converge cross-references and bibliography passes in 0.8–8.2 ms, compared to 40–60 ms in TeX Live.

📦 100% Self-Contained

Embeds over 15,000 common LaTeX packages, document classes, and precompiled formats inside a 29 MiB compressed in-memory archive. Zero network calls or external TeX installations required.

🛡️ Memory Safe & Robust

Written entirely in pure Rust with strict bounds checking. Completely eliminates buffer overflows, memory leaks, and runaway pointers common in legacy C TeX engines.

🔄 Seamless Workflow

Ships as a standalone texmk driver. Drop it into your existing workspace: texmk paper.tex handles compilation passes automatically without clashing with existing TeX Live setups.

Build from Source (Rust 1.80+) cargo
git clone https://github.com/leoliu0/ratex.git
cd ratex
cargo build --release --bin texmk

# Binary located at target/release/texmk
./target/release/texmk document.tex

Quick Usage

Compiling Documents
# Compile document and automatically converge bibliography and citations
texmk document.tex

# Specify output directory
texmk -output-directory=build document.tex

# Allow using external TeX Live packages if not already embedded
texmk --allow-system-texmf document.tex
